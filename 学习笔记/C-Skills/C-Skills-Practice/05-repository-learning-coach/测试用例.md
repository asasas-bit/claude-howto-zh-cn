# 测试用例：教程仓库学习教练

## 应该触发

```text
我把 03-skills 看完了，基本能看懂，但是自己还不会设计。接下来应该怎么练？
```

预期：诊断处于“会看/初步会解释”，安排一个小型 Skill 设计练习和验收。

## 不应该触发

```text
把 03-skills/README.md 的目录标题改一下。
```

预期：处理普通文档任务，不生成学习计划。

## 边界情况

```text
我一天内想把 Skills、Subagents、MCP、Hooks 和 Plugins 全部学会。
```

预期：说明目标过宽，按依赖关系选一个主目标，而不是制造巨大清单。

## 验收

- 是否先读取真实仓库；
- 是否判断当前学习层级；
- 是否只有一个主要目标；
- 是否包含手做、复述、变式和验收；
- 是否给出完成证据，而非只给阅读列表。

## 失败后改哪里

- 层级判断模糊：修改水平参考；
- 计划结构不稳定：修改模板；
- 一次安排太多：修改 `SKILL.md` 的目标选择规则；
- 替用户动手：加强手动练习边界。
