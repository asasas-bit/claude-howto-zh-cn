# 学习水平判断规则

## L1：会看

- 能认出文件和术语；
- 阅读时觉得大致明白；
- 离开示例后无法说明选择理由。

升级证据：能不用原文复述用途和边界。

## L2：会解释

- 能用自己的话说明概念；
- 能比较相似能力；
- 仍不确定怎样从零开始。

升级证据：能根据一个具体需求选择载体并说明理由。

## L3：会操作

- 能照步骤安装、创建或调用；
- 能通过检查命令确认结果；
- 条件变化时容易卡住。

升级证据：能完成一个改变路径、输入或边界的变式。

## L4：会设计

- 能定义触发、输入、流程、输出和边界；
- 能决定是否需要模板、参考资料或脚本；
- 能指挥 AI 创建最小版本。

升级证据：能独立写验收标准并解释结构取舍。

## L5：会验收和迭代

- 能设计应该触发、不应触发和边界测试；
- 能根据失败定位应该修改的文件；
- 能删除无用复杂度并根据真实问题增加资源。

完成证据：新会话中的真实任务稳定通过，且相较无 Skill 明显减少重复说明或错误。

## 判断原则

- 使用用户产物和行为证据，不只依赖自我感觉。
- 可以在不同主题处于不同层级。
- 一次练习只跨一个主要层级。
