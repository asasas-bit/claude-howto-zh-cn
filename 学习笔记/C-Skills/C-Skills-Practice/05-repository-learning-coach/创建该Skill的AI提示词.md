# 创建 `repository-learning-coach` 的 AI 提示词

```text
请创建一个 Claude Code Skill：`repository-learning-coach`。

用途：读取当前教程仓库、路线图和学习笔记，根据用户真实水平安排下一阶段练习，并用产物、复述和变式题验收，而不是只推荐继续读文档。

创建前先只读检查项目，输出五张需求卡和最小结构。Skill 需要：

- `SKILL.md`：诊断、选目标、设计练习、验收和记录下一步；
- `templates/learning-plan-template.md`：统一学习计划结构；
- `references/learner-level-rubric.md`：定义“会看、会解释、会操作、会设计、会验收”五个层级。

要求：
1. 一次只安排一个主要学习目标；
2. 优先使用仓库已有真实示例；
3. 对新手先在教程仓库做低风险练习；
4. 用户明确要手动练习时，不替用户执行修改；
5. 每次至少包含主练习、一个变式和验收清单；
6. 不把“读完”“感觉懂了”当作完成证据；
7. 不提交或推送 Git；
8. 不创建空目录或额外 README。

创建后解释每个资源的作用，并给出三类测试。不安装，不提交。
```
