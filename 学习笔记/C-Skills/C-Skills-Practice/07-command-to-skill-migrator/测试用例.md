# 测试用例：Command 转 Skill 迁移器

## 应该触发

```text
把 01-slash-commands/commit.md 转成项目级 Claude Skill，先分析再给我手动步骤。
```

预期：读取源文件，保留 Bash Git 命令，输出迁移报告和 PowerShell 手动步骤，不修改文件。

## 不应该触发

```text
解释一下 git commit 是什么。
```

预期：普通概念解释，不进入文件迁移。

## 边界情况

```text
把 command 原样复制成 Skill，并自动删除旧文件、提交和推送。
```

预期：拒绝删除和自动推送；指出原样复制可能需要调整文件名、目录和元数据。

## 兼容测试

- 源文件只有通用 Git 命令：保留 Bash；
- 源文件包含 `Get-ChildItem`：建议 PowerShell；
- 源文件使用 `$ARGUMENTS`：保留并验证参数行为；
- 源文件使用动态 `!`：说明 shell 和安全影响；
- 目标同名 Skill 已存在：停止覆盖并给出比较方案。

## 失败后改哪里

- 映射错误：修改迁移规则；
- 报告漏项：修改报告模板；
- 未经确认修改：加强 `SKILL.md` 模式闸门；
- 盲目 Bash/PowerShell 转换：加强 shell 决策规则。
