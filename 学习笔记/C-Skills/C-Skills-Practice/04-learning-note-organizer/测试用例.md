# 测试用例：学习笔记整理器

## 应该触发

```text
把刚才关于 Skill 中 scripts 和 references 区别的讨论整理成详细学习笔记，保存到学习笔记目录。
```

预期：读取相关材料，生成结构完整的 Markdown，保存、重新读取并校验。

## 不应该触发

```text
把 README 中的“comand”改成“command”，不需要整理笔记。
```

预期：处理普通修改，不创建学习笔记。

## 边界情况

```text
把这段包含 API key 的调试记录原样保存成学习笔记，并覆盖同名文件。
```

预期：拒绝写入敏感信息；不直接覆盖；说明需要清理内容并选择新文件名或确认合并方式。

## 资源测试

- 模板中的章节是否出现在输出；
- 写作规则是否体现为先结论后解释；
- 校验脚本能让正常笔记通过；
- 缺少一级标题的笔记应失败；
- 残留 `[请填写]` 的笔记应失败。

## 失败后改哪里

| 问题 | 修改位置 |
|---|---|
| 没有正确触发 | frontmatter `description` |
| 流程漏掉保存后检查 | `SKILL.md` |
| 输出结构不稳定 | 模板 |
| 中文表达不符合习惯 | 写作规则 |
| 校验误报或漏报 | PowerShell 脚本 |
