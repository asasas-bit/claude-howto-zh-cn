# 可直接使用的提示词：手动练习导师

## 完整提示词

```text
我要亲手练习完成下面的任务，请你做教练，不要替我执行任何会修改文件、Git 状态、配置或外部系统的操作。

任务：
[要完成的任务]

项目路径：
[项目路径]

终端环境：
PowerShell

协作方式：
[逐步模式：一次只给一个步骤，等我反馈 / 完整清单模式：一次给出全部步骤]

你可以先做必要的只读检查来确认项目事实，但必须告诉我检查到了什么。然后按以下要求教学：

1. 先用一句话说明这次最终要做成什么；
2. 说明哪些步骤会产生真实修改，哪些只是检查；
3. 使用适合 PowerShell 的命令；
4. 简单的 `cd`、`mkdir`、`cp` 能满足需求时就使用简短写法，不为了形式统一改成长命令；
5. 不要因为我在 PowerShell 中启动工具，就自动把 Skill 内部的 `Bash(...)` 改成 `PowerShell(...)`，应先判断实际命令是否存在兼容问题；
6. 每一步必须包含：目的、要输入的命令、预期结果、怎样检查；
7. 命令中出现路径时，使用我的真实项目路径，不保留 `/path/to/...` 占位符；
8. 如果某一步失败，先根据错误诊断，不要跳过或直接替我操作；
9. 涉及覆盖、删除、提交、推送、发布或外部写入时，提前明确提醒；
10. 最后给出验收命令和一份最短操作清单。

除非我明确改变要求，否则不要替我创建文件、编辑内容、执行 commit 或 push。
```

## 一次性使用示例

```text
任务：把 01-slash-commands/commit.md 手动复制成 Claude Code 项目 Skill。
项目路径：D:\cc\claude-howto-zh-cn
终端环境：PowerShell
协作方式：逐步模式

请按“手动练习导师”的完整要求指导我，不要替我操作。
```
