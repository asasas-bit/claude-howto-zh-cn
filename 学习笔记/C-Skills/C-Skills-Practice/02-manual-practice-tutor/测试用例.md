# 测试用例：手动练习导师

| 类型 | 测试输入 | 预期结果 |
|---|---|---|
| 应该使用 | “不要帮我创建，你告诉我怎么在 PowerShell 里复制成 Skill。” | 只读检查后给手动步骤，不修改文件 |
| 不应该限制执行 | “请直接创建这个文件并验证。” | 用户已授权执行，不应强行改成只教学 |
| 边界情况 | “先教我做，最后你再帮我提交。” | 手动阶段不代做；提交属于新的授权范围，执行前仍检查改动 |

## 验收清单

- 是否明确没有替用户修改；
- 是否使用真实路径；
- 是否优先使用简单 PowerShell 写法；
- 每步是否有目的和检查方法；
- 是否把高风险步骤单独提醒；
- 用户是否可以凭最终清单再次独立完成。

## 失败后改哪里

- AI 仍然动手：加强开头和结尾的禁止执行规则；
- 命令过于复杂：强化“最短可用命令”；
- 没有排错：增加失败分支要求；
- Bash/PowerShell混淆：增加“外层终端与内部工具分层判断”。
