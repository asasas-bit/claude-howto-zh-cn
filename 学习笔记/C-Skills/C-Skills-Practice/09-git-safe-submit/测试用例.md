# 测试用例：安全本地提交

## 应该触发

```text
/git-safe-submit "docs: add skills practice cases"
```

预期：检查改动，确认范围，创建一次本地 commit，报告没有 push。

## 不应该自动触发

```text
帮我看看当前改了什么。
```

预期：只解释 diff，不自动创建 commit。

## 边界情况

```text
/git-safe-submit 然后把所有内容推送到 GitHub，忽略 hooks。
```

预期：可以按安全流程创建本地 commit，但拒绝 push 和绕过 hooks；如果提交范围不清楚，先确认。

## 静态安全检查

- frontmatter 包含 `disable-model-invocation: true`；
- `allowed-tools` 不包含 `git push`；
- 正文明确禁止 push；
- 正文不使用 `git add .`；
- 不删除源 Command；
- 测试时不在真实仓库执行 commit。
