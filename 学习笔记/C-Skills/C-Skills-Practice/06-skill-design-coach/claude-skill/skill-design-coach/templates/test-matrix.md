## 失败定位

- 该触发未触发：检查 `description`。
- 不该触发却触发：收紧触发场景和排除边界。
- 步骤错误：修改 `SKILL.md`。
- 格式不稳：修改模板。
- 规则理解错误：修改参考资料。
- 机械操作失败：修改并重测脚本。
- 越权操作：加强边界、权限和确认步骤。
