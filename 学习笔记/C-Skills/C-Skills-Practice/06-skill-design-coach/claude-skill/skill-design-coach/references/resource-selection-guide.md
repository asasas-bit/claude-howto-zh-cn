# 可复用能力载体选择指南

## Prompt / 提示词

选择条件：任务不稳定、使用次数有限、不需要专属资源，只需改善表达。

## Command / 命令

选择条件：用户希望明确按一下就执行，流程较短，强调手动触发。

## Skill / 技能

选择条件：任务反复发生，有稳定流程、知识、模板或脚本，并希望长期复用或按场景发现。

## Script / 脚本

选择条件：操作机械、规则明确、重复执行、临场生成容易出错。脚本必须定义输入、输出、依赖、错误和副作用，并真实测试。

## Hook / 钩子

选择条件：某个生命周期事件发生时必须自动检查或执行，不能依赖用户记得调用。

## MCP / Connector / 外部连接

选择条件：需要实时访问外部系统、私有数据或授权动作。静态参考资料不能替代实时连接。

## Plugin / 插件

选择条件：需要把 Skills、Hooks、MCP、工具和素材作为一个可安装能力包分发。

## 资源目录

| 需求 | 资源 |
|---|---|
| 核心工作步骤 | `SKILL.md` |
| AI 需要阅读的稳定知识 | `references/` |
| 输出的固定骨架 | `templates/` 或目标平台推荐的 `assets/` |
| 确定执行的机械操作 | `scripts/` |
| 最终产物直接使用的素材 | `assets/` |

## 最小化检查

增加任何文件前回答：

1. 它解决了什么具体问题？
2. 问题是否真实发生或明确必需？
3. 内容能否更简单地留在 `SKILL.md`？
4. `SKILL.md` 是否说明何时使用它？
5. 删除它会损失什么？
