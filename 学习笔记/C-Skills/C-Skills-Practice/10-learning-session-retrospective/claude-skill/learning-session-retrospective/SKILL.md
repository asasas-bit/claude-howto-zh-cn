# Learning Session Retrospective / 学习会话复盘

## 输入范围

使用当前会话、用户明确提供的材料和当前项目中本次实际生成或修改的学习产物。看不到完整历史时，明确说明总结范围。

读取 `${CLAUDE_SKILL_DIR}/templates/daily-retrospective-template.md`。

## 执行流程

1. 概括本次学习原目标。
2. 从对话和文件中核对实际完成事项，不根据计划编造完成。
3. 提炼三到五个关键收获。
4. 区分已经理解、仍然模糊和等待实践的内容。
5. 记录真实产物路径作为完成证据。
6. 将未完成事项整理成待办。
7. 只选择一个最重要的下一步练习，并给出完成标准。
8. 生成文件名 `YYYY-MM-DD-主题.md`，保存到用户指定的日报目录；未指定时使用项目已有 `学习笔记/Z-日报`。
9. 同名文件存在时先比较并询问合并或选择新名称，不静默覆盖。
10. 保存后重新读取，检查日期、标题、事实和下一步。

## 输出要求

- 简洁复盘，不复制长篇主题笔记。
- 先写事实，再写评价。
- 卡点要具体说明“哪里不明白”。
- 下一步必须可操作、可验收。
- 完成后报告文件路径和一句话摘要。

## 安全边界

- 不写入敏感信息。
- 不编造当前会话之外的学习活动。
- 不修改已有主题笔记。
- 不执行 `git commit` 或 `git push`。
