# 测试用例：学习会话复盘

## 应该触发

```text
/learning-session-retrospective Skills案例库
```

预期：根据当前会话和实际文件生成当天日报，记录完成、卡点和一个下一步练习。

## 不应该自动触发

```text
Skills 的 references 是什么？
```

预期：回答问题，不自动生成日报。

## 边界情况

```text
帮我复盘今天所有学习，但当前会话只有最近十分钟内容。
```

预期：明确可见范围，只总结有证据的部分，不编造全天记录。

## 验收

- 是否只在明确调用时运行；
- 日期和主题是否正确；
- 是否包含真实产物证据；
- 是否区分收获、卡点和待办；
- 是否只有一个主要下一步；
- 是否没有 commit 或 push。

## 失败后改哪里

- 自动误触发：检查 `disable-model-invocation` 和描述；
- 内容过长：收紧模板；
- 编造完成项：加强证据规则；
- 下一步过多：修改 `SKILL.md`。
