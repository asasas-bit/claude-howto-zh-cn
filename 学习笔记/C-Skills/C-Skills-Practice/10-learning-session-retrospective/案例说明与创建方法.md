# 案例 10：学习会话复盘

## 1. 原始表达特征

现有 `学习笔记/Z-日报` 已经体现了一个可继续复用的动作：

- 总结今天学了什么；
- 提炼最值钱的知识点；
- 记录卡壳和未完成事项；
- 给出下一步练习；
- 保存为按日期命名的 Markdown。

它与长篇主题笔记不同：日报关注“今天发生了什么”和“下一步做什么”。

## 2. 结构化后的任务定义

> 在用户明确结束或复盘一次学习会话时，根据当前对话和实际产物生成简洁日报，区分已掌握、仍模糊、完成证据和待办；保存到日报目录，避免覆盖，不自动提交或推送。

## 3. 为什么是简单 Skill

流程稳定，只有一个固定日报模板，不需要脚本或大量参考资料。为了避免每次普通问答都生成日报，采用手动调用。

## 4. 五张需求卡

### 触发卡

用户明确调用或要求“总结今天学习”“生成学习日报”“复盘本次会话”时使用。

### 输入卡

- 当前会话；
- 当天生成或修改的学习产物；
- 可选日期、主题和下一步偏好。

### 流程卡

1. 回顾目标和实际完成；
2. 找到真实产物；
3. 区分收获、卡点和待办；
4. 生成下一步最小练习；
5. 保存日报并重新读取。

### 输出卡

- 日期与主题；
- 今日学习；
- 关键收获；
- 完成证据；
- 卡点与待办；
- 下一步练习；
- 一句话总结。

### 边界与验收卡

- 不编造会话中没有完成的内容；
- 不把整篇主题笔记复制进日报；
- 不覆盖同名日报；
- 不自动提交或推送；
- 下一步只有一个主要目标。

## 5. 怎样与 AI 一起创建

先比较已有日报与长篇学习笔记，明确两者边界；再创建单文件 Skill 和一个模板；最后用“正常复盘、普通问题、信息不足”测试。

```powershell
cp -Recurse .\学习笔记\C-Skills\C-Skills-Practice\10-learning-session-retrospective\claude-skill\learning-session-retrospective .\.claude\skills\
```

## 7. Codex 迁移说明

- 保留复盘流程和日报模板；
- Codex frontmatter 只保留 `name`、`description`；
- 模板可以放入 `assets/`；
- 个人安装到 `$CODEX_HOME/skills/learning-session-retrospective/`；
- 通过明确自然语言要求进行复盘，不假设同名斜杠调用；
- Codex 若无法访问完整历史，只根据当前线程和用户提供的产物总结，并说明范围。
